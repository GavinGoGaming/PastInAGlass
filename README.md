# Past in a Glass
Past in a Glass is a cocktail recipe site for instagram user [@pastinaglass](https://www.instagram.com/pastinaglass/) to share their recipes & blog with the world. It uses Sanity's headless CMS for content management as it integrates nicely with Next.js.

## Development
To work on the project, open `frontend/` for the frontend UI and `studio-past-in-a-glass/` for the Sanity studio, then:
```bash
npm install
npm run dev
```
or, for prod
```bash
npm start
```

You can deploy the studio to Sanity via `sanity deploy`. Read more on their docs: [sanity.io/docs/studio/deployment](https://www.sanity.io/docs/studio/deployment)


Editing content is easy, visit the sanity studio's URL, log in with an approved account, and edit away.
